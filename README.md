# 생활 관리 - 대시보드 (React)

개인·사업·근로 활동을 주기별(일일·수시·주간·월간·년간)로 체크하는 앱입니다.

## 실행
```
npm install
npm run dev        # 개발 서버 (http://localhost:5288)
npm run build      # 배포용 빌드 (dist/)
npm run preview    # 빌드 결과 미리보기 (http://localhost:5289)
```

## 화면
- **대시보드(홈)**: 일정 캘린더(날짜를 누르면 옆에 1시간 단위 일정, "+ 일정 추가" 버튼, "음성으로 추가" 버튼 또는 빈 시간 클릭으로 추가), 다가오는 기념일(설정한 D-일수 이내), 오늘 남은 항목, 주간·월간·년간 도래일(D-day), 도래일 요약, 일일·수시체크의 영역별·카테고리별 요약
- **체크리스트**: 카테고리별·우선순위순 전체 체크리스트 (대시보드에서 카테고리를 누르면 해당 영역·주기로 바로 이동)
- **상세 내용**: 개인활동, 사업활동, 근로활동
  - 영역 페이지: 카테고리를 버튼(타일)으로 보여줌 (세부 항목, 주기별 개수, 오늘 남은 개수, 진행률)
  - 카테고리 페이지: 타일을 누르면 들어가는 상세 화면 (주소 `#/P/건강 관리` 형식, 브라우저 뒤로가기 지원)
- **진행 현황**, **설정**(주기 규칙 확인, 기념일 관리와 표시 기간, 데이터 초기화)

## 파일 구조
```
src/
  main.jsx     진입점
  shared.jsx   공통 요소 (앱 상태 Context, ActionRow, 영역 색상)
  categories/  카테고리 상세 화면
    index.js        카테고리별 전용 화면 등록표
    DefaultView.jsx 등록하지 않은 카테고리의 기본 화면
  App.jsx      화면과 상태 (캘린더, 체크리스트, 상세 페이지, 결과 패널)
  data.js      액션 178개 데이터, 주기 계산(periodKey, isDue), 기본 우선순위
  holidays.js  2026년 대한민국 공휴일(대체공휴일 포함)
  anniv.js     기념일 예시 데이터와 다음 도래일(D-day) 계산
  voice.js     음성 인식 및 한국어 문장 → 날짜·시간·제목 분석
  mock.js      API·AI 시뮬레이션 예시 응답 (실제 연동 시 이 파일을 교체)
  styles.css   스타일 (다크 모드 포함)
```

## 카테고리 전용 화면 만들기
1. `src/categories/DefaultView.jsx`를 복사해 새 파일을 만듭니다 (예: `HealthView.jsx`).
2. `src/categories/index.js`의 `CATEGORY_VIEWS`에 `'영역|카테고리'` 키로 등록합니다.
   ```js
   import HealthView from './HealthView.jsx';
   export const CATEGORY_VIEWS = { 'P|건강 관리': HealthView };
   ```
3. 화면은 `{ area, cat, group }`을 받고, `useCtx()`로 체크·실행 등 앱 기능을 씁니다.

## 동작 규칙
- 체크 상태는 주기별 기간 키(일일=날짜, 주간=ISO 주, 월간=월, 년간=연)로 저장되어 기간이 바뀌면 자동으로 새로 시작합니다.
- 도래 규칙: 일일은 매일, 주간은 매주 일요일, 월간은 매월 말일, 년간은 매년 12월 30일입니다.
- 도래한 날에는 대시보드 상단에 해당 주기 요약이 강조되어 나타나고, 캘린더에도 주간·월간·년간 표시가 붙습니다.
- 체크리스트에는 오늘 도래한 주기만 기본 표시되고, 주기 버튼으로 바꿀 수 있습니다.
- 우선순위 배지를 누르면 높음 → 중간 → 낮음 순으로 바뀝니다.
- API·AI 항목의 "실행"은 예시 응답을 재생하는 시뮬레이션이며, 캘린더 일정 등록 API는 홈 캘린더에 일정을 추가합니다.
- 음성으로 추가: 브라우저 음성 인식(Chrome·Edge·Safari)으로 "내일 오후 3시 반 치과 예약"처럼 말하면 날짜·시간·제목·영역을 채운 추가 창이 열립니다. 마이크를 쓸 수 없으면 문장을 직접 입력해도 같은 방식으로 분석합니다.
- 캘린더: 일요일·공휴일은 빨간색, 토요일은 파란색으로 표시하고 공휴일 이름과 기념일을 날짜 칸에 보여줍니다.
- 기념일: 기본 D-10일 이내 기념일을 대시보드에 모두 보여주며, 설정에서 표시 기간과 기념일 목록을 바꿀 수 있습니다.
- 데이터는 브라우저 localStorage(`lifeboard.react.v1`)에 저장됩니다.
