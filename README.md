# Jcalender - 대시보드 (React)

개인·사업·근로 영역의 활동을 주기별(일일·수시·주간·월간·년간)로 체크하는 앱입니다.

## 실행
```
npm install
npm run dev        # 개발 서버 (http://localhost:5288)
npm run build      # 배포용 빌드 (dist/)
npm run preview    # 빌드 결과 미리보기 (http://localhost:5289)
```

## 화면
- **대시보드(홈)**: 맨 위에 오늘 남은 항목과 주간·월간·년간 D-day, 그 아래 일정 캘린더(날짜를 누르면 옆에 1시간 단위 일정, "+ 일정 추가" 버튼, "음성으로 추가" 버튼 또는 빈 시간 클릭으로 추가), 다가오는 기념일(설정한 D-일수 이내), 구매해야 할 물품, 도래일 요약, 맨 아래 통합 연간 일정표(개인·사업·근로 모든 목표)
- **체크리스트**: 카테고리별·우선순위순 전체 체크리스트 (대시보드에서 카테고리를 누르면 해당 영역·주기로 바로 이동)
- **상세 내용**: 개인, 사업, 근로
  - 영역 페이지: 카테고리를 버튼(타일)으로 보여줌 (세부 항목, 주기별 개수, 오늘 남은 개수, 진행률)
  - 전용 상세 화면이 만들어진 카테고리는 타일 제목 옆에 "완료" 표시 (이제 모든 카테고리)
  - 카테고리 페이지 오른쪽 위 "검수 완료로 표시" 버튼: 마음에 드는 화면을 검수 완료로 표시하면 타일에 "검수 완료"가 붙습니다 (다시 누르면 취소)
  - 카테고리 페이지: 타일을 누르면 들어가는 상세 화면 (주소 `#/P/건강 관리` 형식, 브라우저 뒤로가기 지원)
  - 전용 화면: 개인 › 건강 관리(삼성 헬스 데이터 가져오기, 운동·수면·식단·병원 진찰 탭), 개인 › 기념일 관리(다가오는 기념일, 12개월 목록, 기념일 편집), 개인 › 개인 재무(지출 관리, 구매해야 할 물품, 분류별 지출, 예산), 개인 › 인맥 관리(바로 전화하기·문자, 다가오는 생일·기념일, 명함 이미지 미리보기와 상세 보기, 만남 메모), 개인 › 여가 관리(여행, 독서, 취미 활동 기록), 개인 › 저널링(일기·기분 달력, 주간 회고, 지난 기록), 개인·사업·근로 › 목표 관리(모든 카테고리 목표를 모은 통합 WBS·연간 일정표·마일스톤)
  - 모든 카테고리 상세 페이지 아래에 그 카테고리의 연간 목표 보드(WBS, 연간 일정표, 마일스톤)가 붙습니다 (개인 › 기념일 관리는 제외, goals.js 의 NO_GOAL)
- **진행 현황**(메뉴에서 대시보드와 체크리스트 사이, 영역·주기별 완료 수와 일일·수시체크 요약), **설정**(주간·월간·년간 도래일 변경, 기본값 복원, 데이터 초기화)

## 카테고리 전용 화면 만들기
1. `src/categories/DefaultView.jsx`를 복사해 새 파일을 만듭니다 (예: `HealthView.jsx`).
2. `src/categories/index.js`의 `CATEGORY_VIEWS`에 `'영역|카테고리'` 키로 등록합니다.
   ```js
   import HealthView from './HealthView.jsx';
   export const CATEGORY_VIEWS = { 'P|건강 관리': HealthView };
   ```
3. 화면은 `{ area, cat, group }`을 받고, `useCtx()`로 체크·실행 등 앱 기능을 씁니다.

## 동작 규칙
- 체크 상태는 주기별 기간 키(일일=날짜, 주간=ISO 주, 월간=월, 년간=연)로 저장되어 기간이 바뀌면 자동으로 새로 시작합니다.
- 도래 규칙: 일일은 매일, 기본값은 주간 매주 일요일, 월간 매월 말일, 년간 매년 12월 30일이며 설정에서 바꿀 수 있습니다. 월간 기준일이 없는 달(예: 31일)은 그 달 말일에 도래합니다.
- 도래한 날에는 대시보드 상단에 해당 주기 요약이 강조되어 나타나고, 캘린더에도 주간·월간·년간 표시가 붙습니다.
- 체크리스트에는 오늘 도래한 주기만 기본 표시되고, 주기 버튼으로 바꿀 수 있습니다.
- 우선순위 배지를 누르면 높음 → 중간 → 낮음 순으로 바뀝니다.
- API·AI 항목의 "실행"은 예시 응답을 재생하는 시뮬레이션이며, 캘린더 일정 등록 API는 홈 캘린더에 일정을 추가합니다.
- 음성으로 추가: 브라우저 음성 인식(Chrome·Edge·Safari)으로 "내일 오후 3시 반 치과 예약"처럼 말하면 날짜·시간·제목·영역을 채운 추가 창이 열립니다. 마이크를 쓸 수 없으면 문장을 직접 입력해도 같은 방식으로 분석합니다.
- 캘린더: 일요일·공휴일은 빨간색, 토요일은 파란색으로 표시하고 공휴일 이름과 기념일을 날짜 칸에 보여줍니다.
- 기념일: 기본 D-10일 이내 기념일을 대시보드에 모두 보여주며, 개인 › 기념일 관리에서 표시 기간과 기념일 목록을 바꿀 수 있습니다.
- 건강 관리: 최근 7·14·30일 운동 시간과 수면 시간을 그래프 또는 표로 봅니다. 오늘 기록을 넣으면 일일체크의 "운동 기록"·"수면 기록"이 완료됩니다. 목표 수면 시간은 화면에서 바꿀 수 있습니다.
- 구매해야 할 물품: 대시보드나 개인 재무에서 물품을 추가하고 "구매 완료"를 누르면 결제 금액이 개인 재무 지출 내역에 오늘 날짜로 기록됩니다(분류 유지). 구매 취소하거나 그 지출을 지우면 물품이 다시 구매 목록으로 돌아갑니다. 오늘 지출이 기록되면 일일체크의 "지출 입력"이 완료됩니다.
- 목표 관리: 카테고리마다 연 단위로 목표를 세웁니다. 모든 카테고리에 예시 목표가 들어 있으며, 목표가 없는 카테고리에만 한 번 채워지고 직접 만든 목표는 바뀌지 않습니다. 연도를 바꾸면 그 해에 걸친 목표와 마일스톤만 보이고, 일정표는 1~12월로 그려집니다. 목표 › 단계 › 작업 3단계 WBS로 나누고 번호(1, 1.1, 1.1.1)를 자동으로 붙입니다. 작업 진행률은 체크리스트 체크 기록으로 자동 계산됩니다(작업 기간 동안 해야 할 체크 수 대비 실제 체크 수, 수시체크 제외, 기본은 카테고리 전체 체크 항목이며 작업마다 특정 체크 항목으로 바꿀 수 있음). 상위 항목 진행률은 기간 가중 평균이고, 종료일이 지난 미완료 작업은 지연으로 표시됩니다. 마일스톤은 날짜·D-day와 연결 항목을 관리하며, 연결 항목 진행률이 100%가 되면 자동으로 완료됩니다.
- 개인의 "개인 일정/캘린더"와 "습관/루틴 관리", "개인 목표 관리", 근로의 "근태"·"성과 기록"·"커리어 목표 관리"·"업무 인맥/네트워킹"·"성과 기록·회고"·"급여/복지"·"회의/업무 일정"·"직무 학습" 카테고리는 쓰지 않아 목록에서 뺐습니다(data.js 의 HIDDEN_CATS). 다른 항목의 체크 기록이 바뀌지 않도록 데이터 줄은 남겨 두었습니다.
- 근로 "기획·조사" 카테고리는 각 주기 목록 맨 끝에 줄을 덧붙여(수시·주간·월간) 기존 항목 id 가 바뀌지 않게 했습니다. 데이터는 store.plan 에 저장됩니다.
- 개인 상세 내용에서 "개인 재무"는 맨 아래에 보입니다(App.jsx 의 CAT_ORDER, 표시 순서만 바꿈).
- 주간 회고: 잘한 것 · 아쉬운 것 · 다음 주에 할 것으로 쓰고, "초안 채우기"는 그 주의 체크리스트 완료, 운동·수면, 지출, 연락 메모, 일기를 모아 빈 칸에만 채웁니다. 이번 주 회고를 저장하면 "한 주 돌아보고 적기"가 체크됩니다.
- 인맥 관리: 명함 촬영(연속 촬영 → AI 분석 → 온보딩: 결과 확인·관계·생일/기념일·완료, docs/business-card-ai.md). 명함 사진은 긴 변 1,000px 이하 JPEG로 줄여 브라우저에 저장합니다. 카드 아래 작은 명함을 누르면 상세 창이 열리고, 명함을 한 번 더 누르면 원본 크기로 봅니다.
- 인맥 관리 › 엑셀 가져오기: .xlsx 의 모든 시트에서 "이름" 머리글이 있는 표를 찾아 연락처를 읽습니다(src/contactImport.js). 조직도처럼 표가 나란히 있거나 칸이 병합돼 있어도 읽고, 같은 사람(휴대폰 → 이메일 → 이름+회사)은 한 명으로 합쳐 빈 칸만 채웁니다. 엑셀에서 수식으로 깨진 번호는 "번호 확인 필요"로 표시하고, 마지막 가져오기는 되돌릴 수 있습니다. 파일은 브라우저 안에서만 읽습니다.
- 업무 문서: OneDrive 폴더 구조를 읽기 전용으로 봅니다(src/onedrive.js, Microsoft Graph). Azure 앱 등록(SPA) 클라이언트 ID를 넣고 Microsoft 계정으로 로그인하면 연결되며, 토큰은 앱 데이터와 분리된 localStorage 키에 둡니다. 순서는 docs/onedrive-integration.md. 연결 전에는 예시 폴더 구조를 보여 줍니다.
- 체크는 체크리스트 화면에서만 합니다. 상세 내용(개인·사업·근로의 카테고리 화면)에는 체크 기능이 없고, 기록을 추가해도 체크리스트가 자동으로 체크되지 않습니다.
- 건강 관리 · 삼성 헬스: 삼성 헬스 앱 › 설정 › 개인 데이터 다운로드로 받은 폴더를 압축(.zip)하거나 CSV 파일을 골라 "삼성 헬스 파일 불러오기"를 누르면 운동(exercise)·수면(sleep)·식단(food_intake)을 읽어 합칩니다. 같은 기록은 한 번만 들어가고, 처음 불러오면 예시 기록은 지워집니다. 병원 진찰은 삼성 헬스에 없어 직접 입력합니다. 시험용 파일: samples/samsung_health_sample.zip
- 데이터는 브라우저 localStorage(`lifeboard.react.v1`)에 저장됩니다.
