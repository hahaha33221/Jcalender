# Jcalender 알림 서비스 설계 (저널링 알림 기준)

기준: 2026-10-02 · 관련 파일 `src/reminders.js`, `src/notify.js`, `src/categories/ReviewView.jsx`

## 1. 개요

- 목적: 저널링(매일 일기 · 주간 회고)을 정해진 시각에 알려 주고, 같은 구조로 일정 · 기획 마감 · 구독 결제일 알림까지 넓힌다.
- 지금(웹): 저널링 › 알림에서 켜면, Jcalender 가 열려 있는 동안(다른 탭이어도) 1분마다 확인해 브라우저 알림 · 화면 알림을 보낸다.
- 다음(설치 앱): 앱이 꺼져 있어도 울리도록 기기의 예약 알림(로컬 알림) 또는 서버 푸시를 붙인다. 알림 "일정 계산"은 이미 분리해 두어(`upcomingJournal`) 보내는 방법만 바꾸면 된다.

## 2. 안건

| 번호 | 안건 | 내용 |
|---|---|---|
| 1 | 알림 방식 비교 | 웹 알림 · 웹 푸시(PWA) · 설치 앱 로컬 알림 · 설치 앱 서버 푸시 |
| 2 | 필요한 것 | 계정 · 키 · 서버 · 비용 |
| 3 | 저널링 알림 규칙 | 시각 · 요일 · 이미 쓴 날 건너뛰기 · 주간 회고 |

## 3. 안건 별 주요 내용

### 3-1. 알림 방식 비교

| 방식 | 앱이 꺼져 있을 때 | 서버 필요 | 추가 비용 | 적합한 알림 |
|---|---|---|---|---|
| A. 웹 알림 (지금) | 안 옴 (탭이 열려 있어야 함) | 없음 | 없음 | 확인용 |
| B. 웹 푸시 (PWA, 홈 화면에 추가) | 옴 | 있음 (VPS 에서 보냄) | 없음 | 아이폰은 iOS 16.4 이상 · 홈 화면 추가 필수 |
| C. 설치 앱 + 로컬 알림 | 옴 | **없음** (기기가 예약해 둠) | 스토어 등록비 | **저널링처럼 정해진 시각 알림** (추천) |
| D. 설치 앱 + 서버 푸시 (FCM · APNs) | 옴 | 있음 | 스토어 등록비 | 다른 기기에서 바뀐 일정, 공유 알림 |

추천: 앱을 설치형으로 바꿀 때 **C(로컬 알림)로 저널링 · 일정 · 구독 결제일**을 먼저 하고, 다른 사람과 공유하는 알림이 필요해지면 D 를 더한다.

### 3-2. 필요한 것

| 구분 | C. 설치 앱 + 로컬 알림 | D. 서버 푸시 추가 시 | B. 웹 푸시(PWA)로 갈 때 |
|---|---|---|---|
| 앱 포장 | Capacitor 로 지금 React 앱을 감싸기 (`@capacitor/core`, `@capacitor/local-notifications`) | 같음 + `@capacitor/push-notifications` | manifest.json · 서비스 워커 |
| 계정 | Apple Developer (연 $99, 아이폰) · Google Play Console (1회 $25, 안드로이드) | + Firebase 프로젝트(무료) | 없음 |
| 키 · 인증서 | 앱 서명 키 | APNs 인증 키(.p8) · FCM 서버 키(서비스 계정 JSON) | VAPID 키 1쌍 |
| 서버 | 없음 | VPS 에 보내는 기능 + 기기 토큰 표(push_tokens) + 1분마다 보내는 작업 | VPS 에 웹 푸시 보내기 + 구독 정보 표 |
| 개발 도구 | 맥 + Xcode(아이폰), Android Studio(안드로이드) | 같음 | 없음 |
| 사용자 허용 | 처음 실행 때 알림 허용 | 같음 | 홈 화면 추가 후 알림 허용 |

### 3-3. 저널링 알림 규칙 (구현됨)

| 항목 | 내용 |
|---|---|
| 매일 일기 | 켜기 · 시각(기본 21:30) · 요일 선택 · "이미 쓴 날은 알리지 않기" |
| 주간 회고 | 켜기 · 요일(기본 일요일) · 시각(기본 20:00) · 그 주 회고를 썼으면 알리지 않음 |
| 중복 방지 | 알림마다 key(`journal:날짜`, `review:주`) 로 한 번만, 2시간 넘게 지난 알림은 건너뜀 |
| 저장 위치 | `journal.remind` (계정 동기화에 포함 → 다른 기기에서도 같은 설정) |
| 설치 앱 연결 | `upcomingJournal(store, 지금, 7)` → [{ title, body, when }] 을 로컬 알림 예약에 넘김 (앱을 열 때마다 다시 예약) |

## 4. 결론

- 저널링 알림은 지금 웹에서 동작하고(앱이 열려 있을 때), 설치 앱으로 바꾸면 **로컬 알림만 붙이면** 서버 없이 꺼져 있어도 울린다.
- 설치 앱 준비물은 Apple Developer · Google Play 계정, 맥(Xcode)과 Capacitor 포장 작업이다.

## 5. 향후 진행 사항

| 순서 | 할 일 |
|---|---|
| 1 | Apple Developer · Google Play 계정 만들기 (아이폰만이면 Apple 만) |
| 2 | Capacitor 로 앱 포장, 아이콘 · 이름 · 패키지 이름(예: com.koreamate.jcalender) 정하기 |
| 3 | 로컬 알림 연결: 저널링 → 일정 → 구독 결제일 순서 |
| 4 | (필요하면) Firebase · APNs 키를 만들어 VPS 서버 푸시 추가 |

## 6. 기타

- 웹 알림이 안 오면: 브라우저 주소창 왼쪽 자물쇠 › 알림 › 허용, 맥 시스템 설정 › 알림 › 브라우저 허용.
- 아이폰 사파리는 일반 탭에서는 웹 알림을 보낼 수 없다 (홈 화면에 추가한 앱에서만).
